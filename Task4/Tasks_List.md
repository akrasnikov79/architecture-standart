# Список крупных задач для систем (к ADR 4)

### 1. АБС (Автоматизированная Банковская Система)
- Разработка модуля ведения/хранения матрицы депозитных ставок (отказ от Excel-файлов бэк-офиса).
- Настройка логики согласования индивидуальных ставок в интерфейсе АБС.
- Разработка ежедневного PL-SQL джоба для выгрузки актуальных ставок в формате CSV.
- Разработка интеграционного модуля (Java Spring Boot) для шифрования выгруженного CSV и его отправки по SMTP партнеру.
- Настройка асинхронного приема/обработки онлайн-заявок (интеграция с Deposit Service).

### 2. Интернет-Банк (Микросервис Deposit Service)
- Разработка микросервиса (ASP.NET Core) витрины депозитов: API получения списка вкладов и ставок.
- Интеграция с АБС для получения справочника ставок (синхронизация/кэширование).
- Разработка UI (React/ASP.NET) для отображения витрины и формы заявки с подтверждением по СМС.
- Интеграция с СМС-шлюзом из ИБ.
- Слой безопасности: настройка SSL/HTTPS и защиты данных.

### 3. Сайт Банка
- Доработка дизайна и верстки витрины депозитов на сайте.
- Разработка веб-формы для сбора лидов (ФИО, Телефон).
- Настройка защищенной передачи данных по HTTPS в Систему Кол-центра.

### 4. Система Кол-центра (Внутренняя CRM)
- Интеграция с сервисами сайта для приема лидов в CRM.
- Интеграция с БД АБС / Deposit Service для отображения операторам формы с актуальными ставками онлайн.
- Доработка интерфейса карточки клиента и сценариев звонка для продаж депозитов.

### 5. Система Партнерского Кол-центра (Внешняя)
- Настройка почтового ящика для приема файлов со ставками.
- Разработка автоматического парсера зашифрованных писем, извлечения CSV файлов и их загрузки во внутреннюю БД партнера.
- Обновление интерфейсов операторов для отображения ставок из загруженного файла.
